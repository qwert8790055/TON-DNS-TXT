# 防骗研究说明

## 你的情况

如果你使用的是**别人的 Apple ID / 设备**，且**被骗**：

- **不需要**也**不应该**做越狱、破甲、登录他人账号
- **可以**安全地：收集截图、聊天记录、转账记录，撰写警示报告

## 一键生成防骗报告（推荐）

```bash
cd null-order/mobile/pojia

# 方式 1：交互式填写
./scam_report.sh

# 方式 2：编辑配置文件后生成
cp case.env.example case.env
# 填写 case.env
./scam_report.sh --from case.env
```

报告输出：`null-order/reports/NØ-防骗报告-SCAM-*.md`

## 与「破甲行动」的区别

| | 破甲行动 | 防骗报告 |
|---|---|---|
| 目的 | 授权安全研究 | 记录诈骗、警示公众 |
| 需要设备 | 是（本人越狱机） | **否** |
| 需要 Apple ID | 本人账号 | **否** |
| 适用场景 | 逆向分析自有 App | 被骗后取证举报 |

## 立即该做的事

1. **停止转账** — 任何「解冻金」「保证金」都是二次诈骗
2. **保存证据** — 聊天、转账、App 截图
3. **报警** — 110 或 **96110** 反诈专线
4. **国家反诈中心 App** — 举报涉诈应用
