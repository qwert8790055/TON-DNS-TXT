## Challenge

Decode the following `dns_text#1eda` cell (base64 BOC) and extract the UTF-8 text value.

```
te6ccgEBAQEAFwAAKh7aARFoZWxsbyBOVUxMLy9PUkRFUg==
```

(This is a single-chunk dns_text cell encoding a short string.)

## Tasks

1. Parse the BOC with `@ton/core` or Pytonlib
2. Verify prefix is `0x1eda`
3. Read chunk count, length, and UTF-8 payload
4. Explain the TL-B layout: `dns_text#1eda chunks:(## 8) rest:(TextChunks)`

## Tools

```typescript
import { Cell } from '@ton/core';
import { decodeDnsText } from './dnsText'; // this repo

const cell = Cell.fromBoc(Buffer.from('te6cckEB...', 'base64'))[0];
console.log(decodeDnsText(cell));
```

Or use the Mini App read path: `/api/dns-records?address=...`
