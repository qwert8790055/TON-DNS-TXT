## Challenge

Review a Jetton (TEP-74) wallet contract on **testnet** for authorization boundary issues in the transfer flow.

## Scope (Authorized)

- Use a **self-deployed** testnet Jetton OR an official testnet faucet token
- Read-only mainnet analysis of public contracts is OK for writeup
- **No** unauthorized mainnet interaction

## Analysis Checklist

1. **Transfer op** — who can initiate? (`transfer`, `internal_transfer`)
2. **Balance check** — can sender spend others' balances?
3. **Forward payload** — injection or replay risks?
4. **Notification** — `transfer_notification` handler auth
5. **Admin ops** — mint/burn/change_admin if exposed
