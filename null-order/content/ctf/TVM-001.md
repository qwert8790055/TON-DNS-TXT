## Challenge

Given a `dnsresolve` response containing a `Hashmap 256 DNSRecord` root cell (base64 BOC), enumerate all `dns_text` entries.

### Steps

1. Call `dnsresolve(category=0)` on an NFT item with multiple records
2. Parse the Hashmap with `Dictionary.loadDirect` (BigUint 256 keys, Cell values)
3. Filter cells where first 16 bits = `0x1eda`
4. Decode each to UTF-8

## Starter Code (this repo)

```typescript
import { parseDnsTextRecords } from './dnsText';

const records = parseDnsTextRecords(bocBase64);
for (const r of records) {
  console.log(r.keyHash, r.value);
}
```

## Task

Use TonCenter or this repo's API:

```
GET /api/dns-records?address=<nft-item-address>
```

Find a domain with ≥2 dns_text records. List all key hashes and values.

## Flag Format

```
NØ{count}:{first_key_hash_8chars}
```

Example: `NØ3:a1b2c3d4` — 3 records found, first hash prefix `a1b2c3d4`
