## Challenge

Complete a verified NULL//ORDER on-chain identity binding on **testnet**.

## Requirements

1. Own a testnet `.ton` domain (or lab-assigned domain)
2. Open `/tools` → TON DNS TXT Mini App
3. Write these records:

| Key | Value |
|---|---|
| `nullorder.telegram` | Your @username |
| `nullorder.role` | `INITIATE` |
| `nullorder.bio` | Your TON focus (e.g. `TVM · dns_text`) |

4. Post proof in NØ//CORE · DNS / IDENTITY:
   - Domain name
   - NFT item address
   - Screenshot or `dnsresolve` output showing records

5. Admin verifies and runs:
   ```
   /task <your_user_id> dns_text_profile yourname.ton
   ```

## Verification Checklist (admin)

- [ ] `dnsresolve` returns all three keys
- [ ] `nullorder.telegram` matches Telegram username
- [ ] Connected TonConnect wallet = NFT owner
- [ ] Network is testnet (or authorized lab domain)

## Flag Format

```
NØ{domain.ton}:verified
```

## Why This Matters

See NØ//RESEARCH-001: public read + owner-only write means **apps must verify**, not just read.
