## Challenge

Analyze a `change_dns_record` message body. Extract:

1. Operation code
2. Query ID
3. Category key (256-bit)
4. Whether this is a **set** or **delete** operation

### Message body (base64 BOC)

Build one yourself on testnet, or use this structure:

```
Op:     0x4eb1f0f9  (change_dns_record)
Query:  0
Key:    sha256("nullorder.role") as uint256
Value:  dns_text cell with "INITIATE" (present = set)
```

## Tasks

1. Deserialize the message body cell
2. Identify set vs delete (hint: presence of value ref)
3. Map the category key back to key name if possible
4. Explain who can send this message successfully

## Flag Format

```
NØ{op_hex}:{action}
```

Where `action` is `set` or `delete`.

Example: `NØ4eb1f0f9:set`
