## Challenge

TON DNS stores `dns_text` keys as **SHA-256 hashes** on-chain. The original key name is not stored.

Find the **original key string** that produces this hash:

```
4c7262423762cb87a9b1251debe634f773a90a04bdb3e4d23b97a50e93b8a135
```

Hint: it's a NULL//ORDER schema key used for Telegram binding.

## Tasks

1. Compute SHA-256 of candidate key names until match
2. Explain why TON DNS uses hashed keys (TL-B `Hashmap 256`)
3. Submit the key name + one paragraph on security implications
