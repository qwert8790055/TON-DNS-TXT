# 微信接粉中台 · 产品演示说明（发给客户）

---

## 一、产品简介

**微信接粉中台** 是一套专为电销团队设计的客户承接系统，支持：

- ✅ **服务号 + 订阅号** 双通道同时接入
- ✅ **一人一码** 渠道追踪（统计每个坐席的转化）
- ✅ **H5 承接页** 自动采集手机号（短信验证）
- ✅ **转三方** 支持 API 推送 / 带参跳转 / 人工导出
- ✅ **管理后台** 线索查询、数据看板、CSV 导出

---

## 二、业务流程

```
电销接通 → 发送专属渠道二维码 → 客户关注公众号/服务号
→ 自动欢迎语 + H5登记页 → 短信验证手机号 → 线索自动入库
→ 实时推送/跳转至三方平台 → 后台可查看转化数据
```

## 五、三方对接方式

### 方式 1：API 实时推送（推荐）
线索登记完成后，系统自动 POST 至三方接口：
```json
{
  "lead_id": "唯一线索ID",
  "mobile": "13800138000",
  "channel_code": "坐席渠道码",
  "agent_name": "坐席A",
  "account_type": "service"
}
```

### 方式 2：带参跳转链接
客户登记完成后自动跳转：
```
https://三方域名/register?lead_id=xxx&mobile=xxx&channel=xxx&sign=xxx
```

### 方式 3：人工导出
后台一键导出 CSV，运营手动导入三方。
